The claim

Built on the CSTA K-12 Computer Science Standards

The CSTA standards describe what students should learn about computing at each grade band, and they are what computer-science classrooms in the United States follow. This course is aligned to CSTA K-12 standards at Level 2 (the grades 6-8 band) in Computing Systems, Networks and the Internet, and Algorithms and Programming, taught through MakeCode block programming of a real ElecFreaks Cutebot robot car.

Every chapter names the standard it delivers in its own source file, and every code printed on this page is read back out of those files when the page is built. A code that does not exist in the official standard cannot get here: the build checks each one against a registry of all 62 standards up to the course ceiling and stops if it finds a code that is not in it.
