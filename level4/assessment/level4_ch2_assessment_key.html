📝 Notes for this chapter

The three-branch shape (if / else if / else) is the real content. Draw a number line on the board: under 5, 5 up to 9, 10 and over. Fix It answer: two things are wrong. The wide test comes first, so the narrow one never runs — anything under 5 is already under 10. And the forward block sits in the < 10 branch, so the car drives into your hand. Put < 5 first, and make < 10 stop. The 2 cm floor from last chapter is gone on purpose: a 0 reading now lands in too close, and backing off is the safe answer. Source: ElecFreaks wiki, Case 10 "Car Following with A Fixed Distance".

🧩 The blocks you need today

logic_else_if

Adds another test for when the one above it was false.

if (input.buttonIsPressed(Button.A)) {
    cuteBot.forward()
} else if (input.buttonIsPressed(Button.B)) {
    cuteBot.backforward()
} else {
    cuteBot.stopcar()
}

You see: The first test that is true wins and the rest are skipped.

Talk rubric

Strong — says a chain stops at the first true test so exactly one branch runs, whereas separate if blocks are all checked and a later one can overwrite an earlier decision. Developing — says only one branch runs in a chain, without saying what goes wrong otherwise. Needs Focus — treats the two forms as equivalent.
