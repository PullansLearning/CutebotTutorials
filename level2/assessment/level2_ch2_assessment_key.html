📝 Notes for this chapter

⚠️ The extension's names look backwards: the block labeled Right_RGB is RGB_L in code, and Left_RGB is RGB_R. Trust the label on the block, not the letter in the name — that is what the students will see and what this chapter uses. (Verified against the official MakeCode renderer, 2026-08-18.) The rainbow LEDs are not Cutebot blocks. They live on pin P15 and need the neopixel extension, set up once in on start. This is the first chapter with two extensions at the same time. Fix It answer: no pause between on and off, so the blink is far too fast to see — the lamp never looks lit. Source: ElecFreaks wiki, Case 06 "Steering & Clearance Lamps".

🚀 Extend — where each task goes

🟢 The wiki asks this one: make button A turn both lights on and button B turn them off.
Notice that is not a blink at all → Decide what each button should do once → Take the repeat out → Test that they stay as you left them🟡 Make the car turn while its signal blinks, like a real car.
Recall which two numbers make a turn → Put the motor block with the blink → Match the turn time to the blink time → Stop the wheels at the end🔴 Add hazard lights — both sides blinking together.
Decide which button is free → Blink left and right in the same repeat → Keep the two sides in step → Say how a driver tells this from a turn signal

🧩 The blocks you need today

neopixel_create

Gets the rainbow lights ready, which you do once at the start.

let strip = neopixel.create(DigitalPin.P15, 2, NeoPixelMode.RGB)
strip.showColor(neopixel.colors(NeoPixelColors.Blue))

You see: Nothing on its own. Here the next block turns both lights blue.

neopixel_set_pixel

Picks the color for one rainbow light without showing it yet.

let strip = neopixel.create(DigitalPin.P15, 2, NeoPixelMode.RGB)
strip.setPixelColor(0, neopixel.colors(NeoPixelColors.Red))
strip.show()

You see: The first light turns red, but only because the show block runs after it.

neopixel_show

Sends the colors you picked to the lights.

let strip = neopixel.create(DigitalPin.P15, 2, NeoPixelMode.RGB)
strip.setPixelColor(1, neopixel.rgb(0, 200, 80))
strip.show()

You see: The rainbow lights under the car change to the colors you set.

neopixel_colors

A ready-made color you can drop into a rainbow block.

let strip = neopixel.create(DigitalPin.P15, 2, NeoPixelMode.RGB)
strip.showColor(neopixel.colors(NeoPixelColors.Yellow))

You see: One color value, like red or green.

loops_repeat

Runs the blocks inside a set number of times.

for (let i = 0; i < 4; i++) {
    cuteBot.forward()
    basic.pause(500)
    cuteBot.turnright()
    basic.pause(400)
}
cuteBot.stopcar()

You see: The blocks inside run again and again until the count is finished.

cutebot_color_light

Turns a headlight on in the color you pick.

cuteBot.colorLight(cuteBot.RGBLights.ALL, 0xff0000)
basic.pause(2000)
cuteBot.closeheadlights()

You see: The headlight you named glows in that color until you change it.

Talk rubric

Strong — pairs repeat with the indicator because it runs a set number of times and stops, and a plain on-block (no loop) with the headlights because they should stay as they are. Developing — names the right blocks but does not say why. Needs Focus — uses forever for the indicator, or treats the two as the same job.
