🧑‍🏫 Teacher Guide

📝 Notes for this chapter

The sensor is the micro:bit's LED screen, not a Cutebot part. The wiki uses 10 as the threshold, but that number belongs to their room — have pairs shade the screen and find a value that actually works. Fix It answer: > instead of <, so the lights come on in daylight and go off in the dark — backwards. Source: ElecFreaks wiki, Case 05 "Automatic Headlights".

🚀 Extend — where each task goes

🟢 Find the number that fits your own classroom and use it instead of 10.
Set your number to 10 and switch on → Carry the car from the window into a shadow → Raise or lower the number until the lamps flip exactly where you want → Write down the number that worked🟡 The wiki asks this one: show a different color the longer it stays in the dark.
Decide how you would count the time in the dark → Pick two or three colors in order → Change the color as the count grows → Reset the count when it gets light🔴 Make the headlights fade in instead of snapping on.
Notice the lights take a number 0 to 255 → Find a way to climb that number → Do it a step at a time → Fade back down when it gets light🟡 Keep the dark test, but also light up for the first three seconds after switch-on so people see it start.
Decide what should happen the moment it switches on → Put that before the loop → Hold it three seconds → Let the loop take over

🧩 The blocks you need today

input_light_level

Reads how bright the room is, from 0 to 255.

basic.showNumber(input.lightLevel())

You see: A small number in the dark and a big number in the light.

cutebot_headlight_rgb

Mixes your own headlight color from red, green, and blue amounts.

cuteBot.singleheadlights(cuteBot.RGBLights.RGB_L, 255, 120, 0)

You see: The headlight shows the mixed color — 255 is full and 0 is off.

Talk rubric

Strong — says the sensor reports a number that depends on the room's own light, so the split point has to be measured where the car will be used. Developing — says rooms are different without mentioning that the reading is a number you measure. Needs Focus — says the sensor is broken or that one number should work everywhere.
