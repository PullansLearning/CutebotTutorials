📚 Words to know

🔶
clearance lamp
The small light underneath that shows where the car is.
🎗️
LED strip
A row of lights on one pin, counted from 0.
🔁
repeat
Do these blocks a set number of times, then stop.
↗️
signal
A light that tells other people what you are about to do.
🔧
set up
Tell the program the strip exists before you can use it.

🌍 In the real world

Every indicator on the road works this way — on, pause, off, repeated. Without the pause it would be a steady light, and steady means something else entirely.

    1. Add both extensions: Cutebot and neopixel.
    2. In on start, set up the two rainbow LEDs on pin P15.
    3. On button A, blink the right-hand pair once.
    4. Add a second pause (500) after the off blocks so the lamp stays dark for a moment, wrap the blink in a repeat so it happens five times, and mirror the whole thing onto button B.

    🚗 Drive test

    Count the blinks out loud. Five, then it stops on its own — that is repeat doing its job. Then check that A and B light opposite sides.

    💡

    The strip must be set up in on start. If you set it up inside the button block it will be rebuilt on every press, and the lights get confused.
