🧑‍🏫 Teacher Guide

📝 Notes for this chapter

Test at a real table edge, but keep a hand under it for the first run. The escape is: reverse, wait, turn a random amount, wait, stop and wait a second — then the loop creeps forward again. Random matters — a fixed turn can walk the car along the edge forever. Fix It answer: the escape turns before it reverses, so a wheel goes over the edge during the turn. Source: ElecFreaks wiki, Case 07 "Fall-arrest Cutebot".

🚀 Extend — where each task goes

🟢 Make the car show something on its screen the moment it finds the edge.
Find where the escape begins → Choose an icon that means stop → Put it at the start of the escape → Show Happy again when it drives on🟡 Test it on a table corner. Report what happens and why.
Set it going towards a corner → Watch which probe loses the surface first → Write down what the car did → Explain it using the two probes🔴 Make the escape smarter: back up further when it is going faster.
Notice the creep speed is a number you chose → Decide how the reverse should relate to it → Change the escape to match → Test at two different creep speeds

Talk rubric

Strong — says the sensors sit at the front so the car is already partly over the edge, and turning there swings a wheel out over the drop; reversing puts it back on solid ground first. Developing — says reverse comes first without explaining what turning would do. Needs Focus — says the order does not matter, or describes only the turn.
