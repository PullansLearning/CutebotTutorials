📚 Words to know

📦
variable
A box with a name that holds a number you can change.
🎚️
speed
How fast a wheel turns, from -100 to 100.
♾️
forever
Blocks here run again and again, without stopping.
➕
change by
Add a number to what a variable already holds.
📈
gradually
A little at a time, instead of all at once.

    4🗺️ Plan

    One number does all the work. Make the box, put it on both wheels, then push it up a little at a time.

    🗺️ Your game plan

    1. 📦Make a speed box and put 0 in itOn start, before anything moves.
    2. ⚙️Give both wheels the speedLeft and right take the same number, so it goes straight.
    3. ➕Push the speed up by 1Every time round the loop.
    4. 🔁Send it back to 0 at the top100 is as fast as the wheels go.

    5🔨 Build

    ▶ Open MakeCodeKeep it open beside this page — you will build the blocks there, step by step.

    0 of 5 steps done

    1. Add the Cutebot extension: Extensions (just below Math) → search "Cutebot".
    2. In on start, show an icon and make a variable called speed, set to 0.
    3. In a forever loop, give both wheels the speed.
    4. Still inside the loop, add 1 to the speed, and send it back to 0 when it reaches 100.
    5. Download, unplug, switch on, and put the car on the floor.

      🎮 Your finished project

      Speed Up Gradually

    🚗 Drive test

    Watch the front wheel as it pulls away. It should stay on the floor. Then watch for the moment it drops back to a crawl — that is the box going back to 0.

    💡

    The speed box must be made in on start, not inside the loop. Made inside, it would go back to 0 every time and never climb.
