📝 Notes for this chapter

Floor, and be ready to catch it — this car reverses without warning. The wiki program holds each random pair for one second (pause 1000). Without that pause the speeds change about 50 times a second and the car only shivers. Fix It answer: the range starts at 0, so the wheels can never run backwards and the car only ever curves forwards. Source: ElecFreaks wiki, Case 04 "Run at Random".

🚀 Extend — where each task goes

🟡 Keep the wandering, but stop it from ever driving backward.
Find the two numbers that set the range → Decide which one lets it reverse → Change only that one → Watch a full minute to be sure🟡 Make it wander for ten seconds and then stop by itself.
Find a way to count the time → Decide where the counting goes → Choose the block that stops the wheels → Test with a stopwatch🔴 Make the car wander but stay inside a chalk circle on the floor.
Work out what the car would need to sense → Check which sensor you have met so far → If none fits, say what you would need and why

Talk rubric

Strong — says the car is doing exactly what the program says, and that unpredictability was chosen on purpose by using the random block. Developing — says it is not broken but does not point to the random block as the deliberate cause. Needs Focus — agrees that it is broken, or says the micro:bit changes the program.
