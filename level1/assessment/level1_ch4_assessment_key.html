📝 Notes for this chapter

Big floor space. The eight needs roughly a meter each way. The wiki gives the speeds (100/40, then 40/100) and a 1000ms curve; its straight is 400ms, ours is 200ms. The floor still changes the result — test and adjust. That is the lesson: the floor decides. Fix It answer: both wheels the same, so it never curves — it just goes straight. Source: ElecFreaks wiki, Case 03 "Dance in Figure-of-eight".

🚀 Extend — where each task goes

🟢 The wiki asks this one: make the Cutebot drive a square instead of an eight.
Count the corners a square has → Decide what one corner needs → Make one straight and one corner → Repeat it four times🟡 Drive a triangle. Say how many turns it needs and how big each one is.
Count the corners → Work out how far round each corner goes → Time one corner on the floor → Put three of them in a loop🔴 Make the two loops of the eight different sizes — one big, one small.
Find which number sets the loop size → Change it for one loop only → Keep the straights the same → Test that it still closes into an eight

🧩 The blocks you need today

basic_pause

Makes the micro:bit wait before doing the next thing.

basic.showIcon(IconNames.Happy)
basic.pause(2000)
basic.showIcon(IconNames.Sad)

You see: A happy face, a two second wait, then a sad face.

⚠ The number is in milliseconds — 1000 is one second. Students often type 1 expecting one second and see nothing change.

Talk rubric

Strong — says there is no turn block and that a turn comes from giving the two wheels different speeds, and that the size of the difference sets how tight the curve is. Developing — says the wheels have different speeds without linking that to the shape of the curve. Needs Focus — says the car steers, or that a turn block exists somewhere.
