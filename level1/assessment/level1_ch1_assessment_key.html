📝 Notes for this chapter

Batteries in before anything else. Hand out cars switched off. Fix It answer: show icon holds for about 0.6 s, so the class does see the happy face — then the sad one replaces it and stays. The bug is not that the happy face is invisible; it is that the last icon block wins. Source for this chapter: the ElecFreaks wiki pages "Introduction to Cutebot" and "Safety Instructions".

🧩 The blocks you need today

basic_on_start

Everything here runs one time, the moment the micro:bit wakes up.

basic.showString("HI")

You see: The letters H and I slide across the screen once, then the screen goes dark.

⚠ It does not repeat. If a student says "it only worked once", that is this block doing its job — they want forever instead.

basic_show_icon

Puts one of the built-in pictures on the 25 lights.

basic.showIcon(IconNames.Happy)

You see: A smiling face made of lit dots. It holds for about 0.6 seconds, then stays on screen until something else is shown.

⚠ This block waits — about 0.6 s (interval, default 600 ms) before the program moves on. Two icon blocks in a row are both visible; the second one then stays. To clear the screen you need clear screen.

Talk rubric

Strong — names both parts and gives each a job (micro:bit = brain holding the program, Cutebot = body with motors and sensors that carries it out). Developing — names both parts but only gives one a job. Needs Focus — repeats that they are different without saying what either one does.
