📝 Notes for this chapter

Two micro:bits per pair, and two different programs. Give each pair a different radio group number or the room will cross-talk. The car program is the finished project below; the remote program is step 2. MakeCode links — remote _9JCE5Ta78DL9, car _eTEdPEKvRHEa. Fix It answer: the two boards are on different groups, so nothing is ever heard. If the car will not move at all, swap its batteries before you read the code — weak cells look exactly like this bug. 🧩 The blocks you need today

radio_set_group

Puts this micro:bit on one radio channel, from 0 to 255.

radio.setGroup(7)
radio.sendNumber(1)

You see: Nothing on its own, but now it only hears micro:bits on the same group.

radio_send_number

Sends one number over the radio.

radio.setGroup(7)
input.onButtonPressed(Button.A, function () {
    radio.sendNumber(1)
})

You see: The other micro:bit on the same group receives that number.

radio_on_number

Runs the blocks inside when a number arrives.

radio.setGroup(7)
radio.onReceivedNumber(function (receivedNumber) {
    cuteBot.motors(receivedNumber, receivedNumber)
})

You see: Nothing until a number comes in, then the blocks inside run.

cutebot_turn_left

One wheel stops and the other drives, so the car pivots to the left.

cuteBot.turnleft()
basic.pause(500)
cuteBot.stopcar()

You see: The car pivots left. Half a second is roughly a quarter turn on a smooth floor.

⚠ How far it turns depends on the floor and the batteries. On carpet the same half second turns much less. Students should measure, not trust a number.

cutebot_turn_right

One wheel stops and the other drives, so the car pivots to the right.

cuteBot.turnright()
basic.pause(500)
cuteBot.stopcar()

You see: The car pivots right, about a quarter turn in half a second.

Talk rubric

Strong — says the number carries no meaning by itself; the receiving program gives it one by matching it in an if and running a chosen block. Developing — says it means "turn left" without noting that the receiver is what decides. Needs Focus — says the radio or the sender decides what happens.
