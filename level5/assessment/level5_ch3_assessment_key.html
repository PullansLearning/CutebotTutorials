📝 Notes for this chapter

The ElecFreaks IR remote is sold separately — it is not in the Cutebot kit, and a TV remote will not work (its buttons send different codes). Without one, pairs build and download the whole program, then test each button on the on-screen remote. If your school has one, pass it round. Infrared needs line of sight — if a car will not answer, check nothing is between the remote and the receiver at the front. This is also the first appearance of stop car immediately. Fix It answer: OK maps to go straight instead of stop, so the car cannot be stopped from the remote at all. Source: ElecFreaks wiki, Case 14 "IR Remote Control Car".

🚀 Extend — where each task goes

🟢 Give one unused remote button a job of your own.
Look at the buttons nobody has used → Pick one and decide its job → Add a branch for it → Test it does not disturb the others🟡 Make the headlights show which command it just received.
Recall the headlight block from Level 2 → Choose a color for each direction → Put one in each branch → Check each branch has its own color🔴 Make a button drive a short shape and stop by itself — a parking move.
Decide the shape and how long each part takes → Recall how you timed moves in Level 1 → Put the whole sequence in one branch → End it with the stop block🔴 If your school has an IR remote — relay race: one board watches the IR remote and passes the command on by radio; the second car has no remote of its own.
Decide which board hears the remote and which one drives → Give both boards the same radio group → Send a different number for each command → Branch on that number at the car

🧩 The blocks you need today

cutebot_ir_received

Runs the blocks inside whenever the remote sends something.

cuteBot.IR_callback(function () {
    basic.showIcon(IconNames.Yes)
})

You see: Nothing until you press the remote, then the blocks inside run once.

cutebot_ir_button

Checks which button on the remote was pressed.

cuteBot.IR_callback(function () {
    if (cuteBot.IR_Button(cuteBot.IRButtons.Up)) {
        cuteBot.forward()
    }
})

You see: True only for the button you named, and false for every other one.

cutebot_stop

Switches both motors off right now.

cuteBot.forward()
basic.pause(1000)
cuteBot.stopcar()

You see: The car drives for one second and then stands still.

⚠ The car does not brake gently — it cuts the power and rolls a few centimeters. Two runs will not stop on exactly the same spot, and that is normal, not a bug.

Talk rubric

Strong — says infrared is light that needs an unbroken path, so people, walls or pointing the wrong way block it, while radio passes through obstacles. Developing — says line of sight is needed without contrasting it with radio. Needs Focus — says the remote or the car is broken, or that infrared is simply weaker.
