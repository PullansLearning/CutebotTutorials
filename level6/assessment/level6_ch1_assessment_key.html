🧑‍🏫 Teacher Guide

📝 Notes for this chapter

Darken the room as much as you can and use a torch. The wiki program uses 50 — that is their room, and it is a starting point, not an answer. Pairs measure their own exactly as in Level 2. That is the point of ending here: the same skill, now on a number that decides whether the robot works at all. Fix It answer: the branches are swapped, so the car drives away in the dark and spins when it finds the light. Source: ElecFreaks wiki, Case 15 "Seeking the Light".

🚀 Extend — where each task goes

🟢 Run it against a partner's car and see whose finds the torch first.
Agree a starting line and a torch position → Run both cars → Note which threshold each pair used → Say why one was faster🟡 Make it stop when it gets close to the light instead of bumping it.
Watch how high the light level climbs as the torch gets close → Pick a number that means close enough → Add that test to the bright branch → Test with the torch on the floor🔴 Free build: pick any two sensors you have met and make the car do something new.

🧩 The blocks you need today

input_light_level

Reads how bright the room is, from 0 to 255.

basic.showNumber(input.lightLevel())

You see: A small number in the dark and a big number in the light.

logic_if_else

Picks one of two paths, one for true and one for false.

if (cuteBot.ultrasonic(cuteBot.SonarUnit.Centimeters) < 15) {
    cuteBot.stopcar()
} else {
    cuteBot.forward()
}

You see: Exactly one of the two groups runs, never both.

basic_forever

Everything inside runs again and again, without stopping.

basic.forever(function () {
    basic.showIcon(IconNames.Heart)
    basic.pause(500)
    basic.clearScreen()
    basic.pause(500)
})

You see: A heart that blinks on and off, about once a second, and never stops.

⚠ A forever with no pause repeats very fast. That is fine for motors (a speed ramp needs it), but a blink needs a pause to be seen.

cutebot_forward

Both wheels start turning forward, and they keep turning.

cuteBot.forward()
basic.pause(2000)
cuteBot.stopcar()

You see: The car drives straight ahead for two seconds, then stops and stays stopped.

⚠ This block only starts the wheels — it does not say how far or how long. Without a stop block the car drives until the batteries die or it hits a wall. Students who leave out the stop block think their program 'crashed'.

logic_compare

Compares two numbers.

if (cuteBot.ultrasonic(cuteBot.SonarUnit.Centimeters) < 20) {
    cuteBot.stopcar()
}

You see: True or false, which you drop into an if block.

cutebot_turn_left

One wheel stops and the other drives, so the car pivots to the left.

cuteBot.turnleft()
basic.pause(500)
cuteBot.stopcar()

You see: The car pivots left. Half a second is roughly a quarter turn on a smooth floor.

⚠ How far it turns depends on the floor and the batteries. On carpet the same half second turns much less. Students should measure, not trust a number.

Talk rubric

Strong — says the sensor gives only a brightness number with no direction in it, and the car finds a direction by turning until the reading rises past the threshold. Developing — says it does not know the direction without explaining how spinning solves that. Needs Focus — agrees that the car knows where the light is, or says it needs a second sensor.
